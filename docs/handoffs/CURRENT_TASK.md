# Опрос УРП: отдельный адрес и вычитка

- Задача: опубликовать кадровый опрос по отдельному нейтральному адресу `/urp/`, исправить орфографию, пунктуацию и формулировки.
- Этап: 8 — отдельный адрес опубликован и проверен.
- Ведущий: Codex.
- Ветка: main; реализация через PR #1.
- Артефакты: index.html, questions.js, app.js, core.js, config.js, tools/browser-qa.py, README.md, документы дизайна.
- Следующее действие: передать кадровой службе новый адрес и получить ответы.

## Требования и статус

- Проверено: независимый адрес https://zakrasava.github.io/urp/ ; отдельный репозиторий без истории и ссылок на другие опросы.
- Проверено: вычитка текстов, единое употребление «ё», исправление тяжёлых формулировок и пунктуации. Условия и вопросы не сокращаются.
- Проверено: все 23 вопроса К01–К23, пять разделов, примеры, девять исходных документов, кнопки копирования сетевых путей и шесть принятых решений сохранены.
- Проверено: прежние оформление, адаптивность, валидация, черновик, отправка, ошибки, повтор без дублей и копирование ответов сохранены.
- Проверено: кадровые Apps Script и закрытая таблица сохранены; код приёмника не меняется. Версия формы 2026-10-08.2.
- Проверено после выпуска: загрузка ресурсов, мобильная и компьютерная вёрстка, реальная отправка, сохранность прежнего действующего опроса.

Принятый объём будущего кадрового портала: все предложенные страницы, шесть ЛНА и автоматизация двух заявлений; компьютер и телефон; дизайн по макетам УРП. Реализация портала ожидает ответы кадровой службы и в текущую задачу не входит.

## Границы и проверки

Исходные кадровые файлы и записи работников не публикуются. Разрешения таблицы и схема приёмника сохраняются. Независимое ревью получает только обезличенный технический снимок: без вопросов кадровой службы, корпоративных путей, документов или ответов.

До публикации: 16 проверок node:test, синтаксис JavaScript, браузерные состояния и размеры 320–1440 px, сохранность идентификаторов и источников, отсутствие сторонних тематических ссылок, git diff --check. После публикации: GitHub Pages commit/status, версия формы, HTTPS-загрузка и подтверждённая отправка синтетического повтора без дубля.

Непроверенные ограничения: реальные мобильные устройства и открытие файлов корпоративного сервера из этой среды.

Локальные результаты: 16 node:test прошли, синтаксис четырёх JavaScript-файлов проверен, браузерная проверка прошла на 320/360/390/768/1440 px. Единственное падение при первом прогоне было устаревшей проверкой текста предупреждения о черновике; проверка обновлена на новую формулировку и дополнена требованием совета скопировать ответы. Полный повтор браузерной проверки прошёл. По скриншотам вёрстка сохранена. Побайтно сохранены приёмник и стили, идентификаторы всех вопросов, назначение документов, их имена и сетевые пути. Ссылок на другие тематические опросы в файлах публикации нет. Все четыре файла прежнего действующего опроса совпадают с исходными SHA-256 локально и на сайте; HTTP 200.

Первое техническое ревью: подтверждённые замечания по проверке подпути и настоящей конфигурации устранены. Браузерная проверка теперь запускает собственный временный локальный сервер, отдаёт только `/urp/`, проверяет настоящий config.js и отсутствие ошибок загрузки ресурсов. После изменений полный браузерный прогон прошёл: project_subpath=true, real_config_verified=true, hr_draft_migration=true. Общий кадровый черновик для двух публикаций одной формы на том же origin сохранён намеренно и описан в README; его восстановление проверено.

Контрольное независимое ревью обезличенного технического снимка: PASS, нет материальных замечаний, блокирующих публикацию. Тесты выполнены на коммите e854909ebd1131034e254b38a17f45305e578dbd: 16 node:test и полный браузерный прогон прошли. Синтаксис JavaScript и git diff --check прошли. Файлы публичного репозитория проверены: нет ссылок или названия других тематических опросов, шаблонов секретов и локальных служебных файлов. Приёмник, доступ к таблице и Google Fonts сохраняются из принятой реализации. Повторная отправка существующего тестового ID после выпуска проверяет связь, CORS, подтверждение и отсутствие дубля; создание строки этим повтором не заявляется.
