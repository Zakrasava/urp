# УРП — уточнения по кадровому порталу

Опрос кадровой службы: 23 вопроса в пяти разделах, пояснения, примеры ответов и ссылки на исходные документы. Оформление сохранено, текст вычитан. Форма адаптирована для компьютеров и телефонов; черновик сохраняется в браузере.

- Адрес: https://zakrasava.github.io/urp/
- Таблица организатора: https://docs.google.com/spreadsheets/d/1PRnjDo_LXdpiYtTd0OvUgVUMe2aDYyPb_MW5mr_gVyc/edit

Ответы записываются в отдельную закрытую Google-таблицу через Apps Script. Успех показывается после подтверждения записи. Повтор с теми же ответами не создаёт вторую строку; изменение ответов сохраняется как новая версия. Схема приёмника и идентификатор кадрового черновика сохранены. Ранняя и новая кадровые публикации в том же браузере используют общий черновик: уже введённые ответы восстанавливаются при переходе на новый адрес.

Исходные PDF/DOC остаются в корпоративной сетевой папке. Ссылки `file://` могут блокироваться браузером; рядом есть кнопка копирования пути для Проводника Windows. Полные документы и сведения о конкретных работниках на сайте не размещаются.

## Проверки

`node --test tests/*.test.cjs` — правила заполнения, источники, восстановление черновика, ошибки, повторы, ограничения приёмника и защита от формул.

Для браузера: `python tools/browser-qa.py`. Проверка сама запускает временный локальный сервер под `/urp/`, проверяет загрузку настоящей конфигурации и ресурсов, затем завершает сервер. Используется уже установленный Playwright. Проверка подменяет сетевые отправки тестовым приёмником, проверяет размеры 320–1440 px, черновик, валидацию, ошибки сети, timeout и повтор.

Реальная проверка использует только кадровый endpoint из `config.js` и синтетическую запись с маркером «ТЕСТОВАЯ ЗАПИСЬ». `python tools/verify-google-sheet.py --test-id <UUID>` проверяет права таблицы и отсутствие дублей через Drive export, без вывода ответов и учётных данных.

## Публикация

GitHub Pages публикуется из ветки `main`, корень `/`. Перед выпуском нужны проверки и ревью. После выпуска проверить адрес, версию `config.js`, загрузку ресурсов и реальную отправку.

Действующий кадровый Apps Script размещён в `apps-script/`; его код и развёртывание при переносе адреса не меняются. Локальный `.clasp.json` исключён из Git. Обновлять можно только проект кадрового приёмника, указанный в этой конфигурации.
