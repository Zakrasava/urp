# Оформление опроса УРП

Сохраняется принятое оформление опроса УРП. Графитовый фон #0a0d14, текст #eef2f8, вторичный текст #a9b3c6, бирюзовый акцент #35d6c3, индиго #6b7cff. Заголовки Unbounded, основной текст Manrope с системными резервными шрифтами. Ширина чтения до 860 px, карточки со скруглением 14 px, поля и кнопки не ниже 44 px.

Одна форма с пятью разделами, навигацией, видимым прогрессом. Примеры и список уже принятых решений раскрываются по запросу. Чёткие подписи, focus-visible, ошибки рядом с полями, отдельные состояния сохранения и отправки. На 320–390 px элементы перестраиваются в одну колонку без горизонтального скролла. Анимация отключается при prefers-reduced-motion.

Состояния: пустая форма, восстановленный черновик, недоступное локальное хранилище, ошибки валидации, отсутствие сети, отправка, ошибка/таймаут с сохранением ответов и копированием, подтверждённый успех. Сетевые документы имеют ссылку, читаемый путь и кнопку копирования; полный PDF не хранится на публичном сайте.
