# УРП — уточнения по кадровому порталу

Опрос кадровой службы, второй круг: 18 вопросов R01–R18 в пяти разделах, у каждого — пояснение, наше предложение или варианты и что нужно от кадровой службы. Первый круг (K01–K23) закрыт, его ответы получены. Оформление сохранено. Форма адаптирована для компьютеров и телефонов; черновик сохраняется в браузере.

- Адрес: https://zakrasava.github.io/urp/
- Таблица организатора: https://docs.google.com/spreadsheets/d/1PRnjDo_LXdpiYtTd0OvUgVUMe2aDYyPb_MW5mr_gVyc/edit

Ответы записываются в закрытую Google-таблицу через Apps Script: второй круг — на отдельный лист «Ответы УРП — круг 2» со своими заголовками; лист первого круга «Ответы УРП» не меняется. Приёмник принимает только набор R01–R18; отправка с вопросами первого круга отклоняется. Успех показывается после подтверждения записи. Повтор с теми же ответами не создаёт вторую строку; изменение ответов сохраняется как новая версия.

Черновик второго круга хранится под ключом `hr-portal-survey:draft:v2`. Черновик первого круга (`v1`) в новые вопросы не подставляется и не удаляется.

## Проверки

`node --test tests/*.test.cjs` — состав второго круга, правила заполнения, восстановление черновика, ошибки, повторы, ограничения приёмника, отдельный лист и защита от формул.

Для браузера: `python tools/browser-qa.py`. Проверка сама запускает временный локальный сервер под `/urp/`, проверяет загрузку настоящей конфигурации и ресурсов, затем завершает сервер. Используется уже установленный Playwright. Проверка подменяет сетевые отправки тестовым приёмником, проверяет размеры 320–1440 px, черновик, валидацию, ошибки сети, timeout и повтор.

Реальная проверка использует только кадровый endpoint из `config.js` и синтетическую запись с маркером «ТЕСТОВАЯ ЗАПИСЬ». `python tools/verify-google-sheet.py --test-id <UUID>` проверяет права таблицы и отсутствие дублей через Drive export, без вывода ответов и учётных данных.

## Публикация

GitHub Pages публикуется из ветки `main`, корень `/`. Перед выпуском нужны проверки и ревью. После выпуска проверить адрес, версию `config.js`, загрузку ресурсов и реальную отправку.

Действующий кадровый Apps Script размещён в `apps-script/`; обновлять его через `clasp push` и то же развёртывание (`clasp deploy -i <deploymentId>`), чтобы адрес в `config.js` не менялся. Локальный `.clasp.json` исключён из Git. Обновлять можно только проект кадрового приёмника, указанный в этой конфигурации.
